SWCanvas — LRU atlas loading + transformed text

Each textbox renders Hello, World ☺ through SWCanvas's fillText, with a random rotation applied via ctx.rotate(...). Fonts are loaded on demand and cached in a bounded LRU (the same AtlasLRU class vendored from BitmapText.js, reused verbatim). The SWCanvas slow path renders text to an intermediate buffer then drawImages with the current transform — that's what makes the rotations work.
To run this demo: ./scripts/download-bitmaptext-assets.sh once to fetch atlases, then either serve over HTTP (e.g. python3 -m http.server from the SWCanvas root) — or run node scripts/wrap-atlases-for-file-protocol.js once to enable file:// loading (adds ~85 MB of base64-wrapped -webp.js files to font-assets/; required because browsers refuse cross-file Image loads under file://).
